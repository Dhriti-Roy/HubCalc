# CalcHub - deployment on Vercel

1. Replace `https://YOUR-DOMAIN.com` with your real domain in every file (find and replace across the folder).
2. Push this folder to a GitHub repository, then import it at vercel.com (Framework preset: Other, no build command).
3. Add your domain under Project Settings > Domains.
4. After Google AdSense approval, paste your AdSense script in the `<head>` of each page and replace the grey "Advertisement" boxes with ad units. Add the `ads.txt` file AdSense gives you to the folder root.
5. Submit `https://YOUR-DOMAIN.com/sitemap.xml` in Google Search Console.
